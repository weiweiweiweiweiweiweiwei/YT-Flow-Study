# YT-Flow-Study

一款專為 YouTube 語言學習打造的瀏覽器擴充功能，幫助你在觀看影片時流暢地查單字、看翻譯，並高效收藏與複習！

---

## ① 安裝指南 (Installation)

由於目前為開源專案版本，請透過以下步驟手動安裝至 Google Chrome 瀏覽器：

1. **下載專案**：點擊本頁面上方的綠色 **`Code`** 按鈕，然後選擇 **`Download ZIP`**，將專案壓縮檔下載到電腦中。
2. **解壓縮**：將下載好的 `.zip` 檔案解壓縮，並記住解壓縮後的資料夾位置。
3. **開啟擴充功能頁面**：打開 Google Chrome 瀏覽器，在上方網址列輸入以下網址並按下 Enter：
   ```text
   chrome://extensions/

 * 啟用開發者模式：在擴充功能頁面的右上角，找到並開啟 「開發者模式 (Developer mode)」 的開關。
 * 載入擴充功能：點擊左上角的 「載入未封裝項目 (Load unpacked)」 按鈕，選擇剛剛解壓縮出來的專案資料夾，即可完成安裝！


## ② 實際操作方式 (Features)
 * 控制列開關與新字幕：在觀看 YouTube 影片時，可以透過控制列的開關自由啟動，畫面中將會顯示專屬的學習字幕。
 * 滑鼠懸停暫停與單字查詢：將滑鼠游標移至字幕上方時，影片會自動暫停；直接點擊單字即可快速查詢中文翻譯。
 * 整句拖曳翻譯：支援滑鼠拖曳選取數個單字或一整句話，輕鬆取得整句英文的對應翻譯。
 * 雙擊一鍵收藏：點擊單字後所彈出的白色翻譯框，只要雙擊 (Double Click) 該框，就能直接將單字/句子收藏起來以便後續複習！
